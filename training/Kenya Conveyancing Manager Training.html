A desktop application from Anthropic. Think of it as an AI assistant that lives on your computer — not in a browser tab.

Foundation #2

What is a plugin?

A plugin is a small package of skills we add to CoWork.

Each plugin teaches CoWork new commands — typed with a forward slash, like /new-conveyance — and connects it to outside services like Airtable, Outlook Calendar, and Outlook mail.

You can have many plugins installed at once. We are installing one: the Conveyancing Manager.

ANALOGY

CoWork is the Microsoft Word window. The plugin is the macro that turns it into a conveyancing assistant.

YOU TRIGGER A PLUGIN BY:
  • Toggling it on for a conversation
  • Typing one of its slash-commands
  • Following the prompts it asks you

21
Opening a new matter

Run

/new-conveyance
IT ASKS YOU FOR
  • Buyer & seller full names · IDs · KRA PINs
  • Property — LR/Title/Plot No. · location · tenure
  • Purchase price · deposit paid · target completion
  • Counterpart advocates & whether seller is a developer
IT THEN DOES, AUTOMATICALLY
  • Creates the matter record in Airtable
  • Calculates all 9 milestone target dates from today
  • Creates 9 Calendar reminders · 7-day & 1-day alerts each
  • Sets the Official Search expiry alert · lodgement + 30 days
  • Drafts Sale Agreement, Engagement Letter, Fee Note

Names and IDs are stored in Airtable — you never re-type them on any future document for this matter.

Extending the system
25
Teaching new LRA forms

Run

/train-form

Out of the box, the plugin generates LRA 33, 63, 58, and 84. For any other LRA form you need, run /train-form — the system auto-downloads the official template from the Ministry of Lands website, analyses its structure, and saves a schema.

Once trained, the form is permanently available in /draft-conveyance-doc. You never train the same form twice.

1

Type the form number

e.g. "LRA 42"

2

Say "no file"

Let the system fetch from the Ministry of Lands.

3

Review the analysis

Confirm or correct field details.

4

Approve the test document

Form is now permanently available.

When things misbehave
26
Troubleshooting

If something looks wrong, here's where to look first.

If you see…Do this
"Cannot find Airtable base"Confirm the base is named exactly Kenya Conveyancing Manager. Rename, then re-run /setup-conveyancing.
"AIRTABLE_API_KEY not set"CoWork → Settings → Environment Variables. Confirm the key is saved with the correct value.
Document downloaded is empty / tinyThe npm package failed. Re-run /setup-conveyancing to reinstall dependencies.
Plugin not showing in CoWorkClick the plugin icon — confirm Kenya Conveyancing Manager is toggled ON for this conversation.
Names on the LRA form are wrongEdit the Conveyance row in Airtable to match the title register, then regenerate the document.
Search expiry not in CalendarCoWork → Settings → Connectors. Reconnect Outlook Calendar, re-run /setup-conveyancing.
