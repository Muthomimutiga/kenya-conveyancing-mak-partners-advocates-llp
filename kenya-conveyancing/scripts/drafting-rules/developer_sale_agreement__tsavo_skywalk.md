## Drafter's Note

Tsavo Skywalk is the **simplest contract** in the portfolio. Construction is complete, Change of User is not required, no DLP, no APCD dependency. From a plugin perspective, this is the **cleanest project to use for the first end-to-end test generation** because there are the fewest moving parts and the fewest conditional clauses. Use this as the smoke test before running Royal Suburb 1 (which exercises the most overrides: arbitration clause, LSK Conditions, omitted electricity line, omitted DLP, etc.).
